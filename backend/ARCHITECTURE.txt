================================================================================
                          ПОТОК ДАННЫХ (REQUEST FLOW)
================================================================================

  HTTP Request (Gin)
        ↓
  Middleware (Logger, Recovery, CORS)
        ↓
  Router → Handler (парсинг параметров, выбор UseCase)
        ↓
  Handler (парсинг DTO, валидация, вызов UseCase)
        ↓
  Use Case (бизнес-логика)
        │
        ├──→ Repository (получение данных из БД)
        │         ↓
        │   Database (PostgreSQL)
        │         ↓
        │   Domain (конвертация в сущности)
        │
        ├──→ Metrics (подсчёт: просмотры, сообщения, покупки, продажи, топ-категории)
        │
        └──→ Achievements (назначение ачивок по условиям)
        │
        ↓
  DTO (конвертация Domain → DTO)
        ↓
  HTTP Response (JSON)

================================================================================
                               ПРИМЕРНЫЕ API ЭНДПОИНТЫ
================================================================================

  GET  /api/profiles                     → Список тестовых профилей
  GET  /api/profiles/{id}                → Профиль по ID
  POST /api/recap/generate               → Запуск генерации итогов
       Body: { "user_id": "uuid", "year": 2025 }
  GET  /api/recap/{user_id}/{year}       → Получить готовый Recap
  GET  /api/recap/{user_id}/{year}/share → Share-card (без чувствительных данных)
  GET  /health                           → Health check

================================================================================
                         ЗАВИСИМОСТИ МЕЖДУ СЛОЯМИ
================================================================================

  Внешний мир (HTTP)
        ↓
  Handlers (Backend 3)  ←─── DTO (Backend 1)
        ↓
  Use Cases (Backend 1) ←─── Repository Interfaces (Backend 1)
        ↓                              ↓
  Domain (Backend 1)        Repository Impl (Backend 2)

  ⚠️ ПРАВИЛО: Зависимости направлены ВНУТРЬ!
     Внешние слои зависят от внутренних, но не наоборот.
